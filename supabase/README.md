# Supabase

Denne mappen brukes av Supabase GitHub-integrasjon og database-migrations.

Når repoet kobles til Supabase:

- Working directory: `.`
- Migrations ligger i `supabase/migrations/`
- Første schema ligger i `20260821093000_initial_padel_manager.sql`

Samme SQL finnes også i rotfilen `supabase_schema.sql` for enkel manuell kjøring i Supabase SQL Editor.
