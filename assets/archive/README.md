# Arkiverte assets

Filer her er ikke en del av runtime-bundlen. De beholdes for historikk og eventuell fremtidig designreferanse.

- `unused-fonts/`: fonter uten aktive `@font-face`-referanser.
- `unused-new-assets/`: tidligere utforskede grafikkfiler som ikke brukes av appen.
- `unused-assets/`: gamle favicon-, bakgrunns-, knapp- og eksempelvarianter uten aktive referanser.
- `visual-redesign/`: designreferanser fra den visuelle redesignfasen.
