## Bug completion rule

A bug is complete only when:

- [ ] Reproduced or clearly verified.
- [ ] Smallest safe fix implemented.
- [ ] Relevant behavior tested.
- [ ] Critical-path regression checked.
- [ ] Status updated.

Do not spend time producing long bug-analysis documents.
